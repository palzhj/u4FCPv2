# Output folder

`run_implementation.tcl` copies the implementation results here:

| File | Description |
| ---- | ----------- |
| `top.bit` | FPGA bit stream (JTAG / Vivado hardware manager) |
| `top.ltx` | debug probes file (ILA in the register file) |
| `top.mcs` | configuration flash image (SPIx4, 64 MB) |
| `top.prm` | configuration flash programming parameters |
